# Beverage reference files

- `Star-Princess-Beverage-Source-Unmodified.md` — original 13-bar source evidence. Contains warnings about vintage, approximate bar coverage, unpriced Good Spirits cocktails, and $15 eligibility.
- `Star-Princess-Beverage-Display-Aliases.md` — the same **210 cocktail rows**, with player-friendly parenthetical explanations added to **136** rows. These additions are **only display text**, never a second ingredient.
- `Ingredient-Display-Alias-Lexicon.json` — optional lookup of ingredient-brand explanatory labels, **not** a normalization map and **not** an importable live game dataset.

The menu reference remains a **historical snapshot**. New onboard photos may supersede selected bar menus. Full production catalog JSON will use the schema implemented and documented by Cursor. The app must keep source ingredients, normalized scoring ingredient keys, and player-readable display labels separate. Never assume unverified Good Spirits prices are within the Princess Plus limit.
